## 更新現有專案
1. 備份整個現有專案，尤其是 union_arena.db 與 static/card_images。
2. 將本版所有 Python 程式、六個 JSON 檔、requirements.txt、templates 與 static/style.css、static/theme.css 複製到你的專案。
   六個 JSON 檔為 series_registry.json、catalog_seed.json、prices_seed.json、buy_seed.json、dorasuta_seed.json、dorasuta_sources.json。
3. 不要覆蓋你正在使用的 union_arena.db，也不要刪除 static/card_images 中已上傳的圖片。
   可以直接替換整個 templates 資料夾；本版已不使用原本的 index.html、edit.html、card_detail.html 等舊模板。
4. 安裝依賴並啟動：

    python -m pip install -r requirements.txt
    python app.py

沿用原本的 CARD_TRACKER_SECRET_KEY、CARD_TRACKER_ADMIN_PASSWORD 環境變數。
啟動會自動補上必要欄位與新分類資料。原本的 CSM1 價格紀錄與手動圖片會自動轉換識別碼，不會被隨附快照覆蓋。
每個尚未擷取過的商品分類才會載入初始快照；不會在每次重啟時覆寫使用者的歷史紀錄。
更新後按 Ctrl+F5 重新載入樣式。

## 操作方式
### 前台
- 圖鑑：選擇作品分類，輸入卡名或卡號搜尋；每頁 24 張，顯示卡圖、效果與觸發效果。
- 悠悠亭：選作品與商品分類，可搜尋日文卡名、卡號、稀有度；每頁 30 件。
- 價格以日圓呈現，缺貨仍保留來源標價，歷史比較僅針對同一商品。

### 管理後台
登入後到「概覽與資料更新」，可查看圖鑑數、行情商品數與待補圖片數。
- 同步圖鑑：更新選定作品的來源卡圖連結、名稱及效果。
- 更新價格：只擷取按下按鈕的商品分類，不會更新其他商品分類。
- 同一分類請求間隔至少 60 秒；無背景排程。失敗保留原有資料。
- 圖鑑與效果：編輯自訂名稱、效果與觸發效果，前台立即採用。清空自訂欄位再儲存，即恢復來源內容。來源同步不會覆蓋自訂內容。
- 圖鑑卡圖／悠悠亭卡圖：可依作品、關鍵字、缺少圖片連結／已手動設定篩選，再上傳新增或替換圖片。
- 手動卡圖優先顯示，來源同步與價格更新都會保留。圖片支援 JPG、PNG、WebP，最大 5 MB。
- 缺圖篩選依資料中的圖片連結與手動圖片判定；有連結但遠端載入失敗時，可自行搜尋該卡並補圖。

## 台幣參考價換算
悠悠亭行情頁新增「換算除數 x」。輸入正數後，以「日幣價格 ÷ x」即時顯示台幣參考價，無條件捨去小數，只顯示整數。
例如：1,000 日圓 ÷ 5 = NT$ 200。
商品清單與歷史價格皆可換算。x 儲存在目前瀏覽器，切換分類、分頁或重新整理會沿用設定；按「清除」即可移除。
未輸入、0、負數或無效數字不會進行換算。若瀏覽器禁止本機儲存，當頁仍可正常換算。
此功能不讀取即時匯率，也不更動資料庫中的日圓價格。
若從上一版 multi_series 更新，僅需替換 templates/yuyutei.html、static/theme.css，並新增 static/currency.js，重整時按 Ctrl+F5。

### 收購頁 /buyback

- 支援作品／商品分類篩選、搜尋、分頁與最近 30 筆收購歷史。
- 台幣換算沿用日幣 ÷ x，無條件捨去小數，與售價頁共用瀏覽器設定。
- 後台概覽每個商品分類新增「更新收購價」；沿用管理員權限、CSRF 與每分類 60 秒限制。更新收購價不會更改售價歷史。
- 圖片與同商品售價共用手動圖片設定，可在原本的悠悠亭卡圖後台新增／替換。
- 價格為店家公告的日文卡片收購參考價，實際收購依卡況及店家受理規則判定，頁面附官方說明連結。

### 推薦頁 /recommendations
不是整份卡表，只顯示符合條件的卡片；已取消每類及每作品張數限制，以每頁 24 張分頁顯示。
所有條件均為程式的篩選規則，不是已驗證的投資模型、預期報酬或保值保證；沒有成交量、全市場行情或再版／賽事消息。

共同門檻：
- 同商品分類＋商品 ID 配對，並交叉核對卡號、稀有度與名稱；不同版本或名稱不一致不硬配對。
- 售價與收購價都需為 7 天內資料，兩者擷取時間差最多 48 小時。
- 店家目前快照為有貨且收購中。
- 售價至少 ¥1,000、收購價至少 ¥500；收購／售價比至少 60% 且小於 100%。

保值候選：
- 依歷史支持、收購／售價比及售價波動排序。
- 缺少長期歷史時，只標示「初步觀察」，推薦理由明確寫出資料不足。
- 至少 3 個不同觀察日跨 14 天，售價變異係數及最大回落皆不超過 20%，才標「有歷史支持」。

增值動能：
- 售價與收購價都需至少 3 個不同觀察日、各跨 7 天以上。
- 兩邊觀察期間的增幅都在 5%–50%，才列為動能候選。
- 依兩邊較低的漲幅排序，並顯示實際觀察期間與漲幅。
- 取最近 90 天資料，每天只使用最後一筆；同日連按更新不會累積觀察日。

本次初始快照可配對 1,590 件商品，取消張數限制後選出 16 張初步保值觀察；沒有跨多天的雙向歷史，故增值動能清單暫空。持續在不同日期更新售價及收購價後，頁面會自動重新篩選。
兩類可能包含同一張卡，因為篩選目的不同。來源資料過期或不符合條件時不會硬湊推薦。

### 收藏候選的依據
- 來源標示的限定序號 AP、親筆或印刷簽名、二星以上特殊稀有度、UR／WINNER 等特殊版本列入研究。一般 AP 不會因為 AP 名稱而自動當成親筆簽。
- 箔押／印刷簽會與親筆分開；只有簽名標示但無法分辨類型時，標為待查。
- CSM 的 AP01★、AP02★、AP03★ 限定序號版本，附上官方「限定 AP／親筆簽企劃」說明。官方頁原文為預定含出演聲優親筆簽，並註明再販封入未定；這是系列版本依據，不能代替單張實物／序號真偽核對。
- 官方說明：https://www.unionarena-tcg.com/jp/products/boosters/csm-1.php?slide=modal
- 不推算未公布的發行量，也不把 PSA 送件／登錄數當成總發行量。
- 不以高店家標價或缺貨本身推定稀少、需求高或一定增值。缺貨、沒有收購價、買賣價差大不會直接排除特殊收藏版本。
- 排序依已填研究欄位數及版本類型，不是預測報酬。未取得可查詢的同版本實際成交紀錄時，不提供合理價或預期增值幅度。
- 店家參考價仍顯示來源、擷取時間與缺貨狀態。Dorasuta 的部分檢索快照會保留可能非即時的標示。

### 後台收藏研究
新增「收藏卡研究資料」入口，可依作品與關鍵字搜尋候選，補充：
1. 版本類型及 HTTPS 來源連結／說明。人工分類為親筆時必須附來源連結與說明。
2. 單卡真偽、證書、流轉來源的核對紀錄。系統不會自動宣稱證書或單卡已鑑定。
3. 卡況、瑕疵、簽名與保存說明。
4. 有來源支持的發行量；填數字時必須提供來源。未知就留空。
5. 同版本、相近卡況的實際成交參考：需金額、日期、可查詢來源及比較說明，不能只填店家在售價。

前台標示為人工登錄資料，研究欄位已填幾項不等於證據已被獨立驗證，也不等於投資評分。可在後台排除／恢復某個收藏候選。
